# Permanent APT channel and safe update preparation — candidate
The portable amd64 package can ship a pinned public archive certificate and a deb822 source. Both are dpkg conffiles. Stable origin proposed: https://framebridge.betancourt.one/debian/stable/, suite stable/main, one amd64 binary for the three validated distributions. The pinned stable fingerprint is 69D0E9D83699F96AB986B06F3C24F85D892A517E. A verified initial DEB is the trust bootstrap; the package never fetches a key or updates APT during maintainer hooks. The stable endpoint must exist and be verified before release; this is not a live publication. Private QA builds use a different ephemeral certificate and offline URI; never publish them. Preserve conffile changes, including Enabled: no, and review old channels explicitly before migration. Removal may retain configuration; purge removes package conffiles. A downgrade to an older package can retain obsolete sources and must be planned.
Prepare APT update from the local tray, or use fb --state-dir PROFILE update prepare. This durable admission gate rejects new managed EXEC jobs without cancelling old work or losing their receipts. Read fb --json update status. Queue drained is not system-wide quiescence: review unknown outcomes, detached effects, other profiles, CUA/TTY and supervisors. Back up affected state, stop applicable services normally, then use the system updater or apt upgrade outside FrameBridge. The cold package guard remains mandatory. On successful verification, start intended profiles and explicitly resume accepting jobs. Older rollback packages do not enforce the new gate.
The job context menu is read-only: exact job details, verified output, and copy job ID. Existing private feedback records and internal job-safety mechanisms are retained for compatibility; there is no review request, cancellation, or edit control in the viewer and no review-task integration in the tray. Ask the authorized administrator in the conversation to investigate. Never replay an unconfirmed job.
