# FrameBridge portable stable mirror

One amd64 package for Debian 13, Ubuntu 24.04 and Linux Mint 22.x.

The official origin is https://framebridge.betancourt.one/debian/stable/. The mirror copies verified signed indexes; it never generates signatures.

Verify the independently trusted archive fingerprint 69D0E9D83699F96AB986B06F3C24F85D892A517E. Use the [official installation and cold maintenance guide](https://framebridge.betancourt.one/download/). Do not enable unattended hot upgrades or overwrite an existing source without review.
