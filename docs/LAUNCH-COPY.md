## Project description

FrameBridge connects ChatGPT to tools running on Linux computers you control. Execute tasks, return to persistent terminals, inspect the real desktop and select approved worker nodes through a central connection. ChatGPT remains hosted; tool execution stays on your machines.

## Pre-release announcement

FrameBridge is preparing a community release for people who want to work with their own Linux computers through ChatGPT. Its recorded RC7 baseline demonstrates command execution, persistent terminals, real console interaction and selected nodes. Preview 2 has passed 376 unit tests; package and VM checks, verified downloads and a fresh real demonstration remain in progress. Pinned dependency terms and actual source-delivery conditions are documented. The project's original code uses GPL-3.0-only within its stated licensing scope.
